# 人际推理原则

## 1. 目标不是“猜中”，而是建立可修正的判断结构

```text
输入
→ 建立判断模型
→ 保持不确定性
→ 选择回应
→ 等待反馈
→ 更新
```

训练质量主要看：是否区分事实与解释、是否保留替代假设、是否知道还缺什么证据、是否考虑误判成本、是否能在新证据出现后真正改变判断。

## 2. 观察优先

先问“我真正观察到了什么”，再问“我把它解释成了什么”。禁止把评价词伪装成事实。

## 3. 多假设并存

任何言外之意分析默认都要问：还有什么别的解释？

不要为了数量机械制造极端可能性，但也不要在证据不足时锁死第一解释。

## 4. 同时寻找支持证据和反证

对每个重要假设，同时问：什么支持它、什么反对它、什么新证据出现会让我改变判断。

只搜支持自己第一反应的材料会导致确认偏差。

## 5. 语境决定含义

同一句话在不同关系、权力差异、文化、过往互动、场合、时间压力、公开或私下、文字或口头条件下，可能具有完全不同的意义。

所以：一句话本身不能直接等于真实意图。

## 6. 先固定字面层，再分析言外之意

```text
字面内容
↓
上下文
↓
可能的言外之意
```

不要跳过字面层直接“解码”。

## 7. 置信度必须跟随证据

证据弱时允许“不知道”“证据不足”“多个解释都合理”。不确定不是失败，而是正确状态的一部分。

## 8. 回应是在不确定条件下做决策

回应不需要等到意图百分之百确定。应比较：如果某个假设为真，这个回应的效果如何；如果它为假，这个回应的代价如何。

信息不足时优先选择可逆、尊重、清晰、不升级冲突、能继续获得信息、能保护必要边界的回应。

## 9. 理解不等于同意

```text
理解
≠
认可
≠
服从
```

人际训练必须保留学习者自己的边界和目标。

## 10. 不对个人过度拟合

不要从少量案例得出“某类人都这样”或“这个人永远会这样”。模式必须包含适用条件与失效条件。

## 11. 预测必须先冻结，再揭示后续信息

如果做预测：

```text
当前时点的预测
↓
冻结记录
↓
揭示下一条信息
↓
比较
↓
更新
```

不能看到结果后修改原预测。

## 12. 复盘重点是“箭头”

复盘不是只问“最后猜对了吗”，而是问：为什么从 A 走到 B、用了什么信号、有没有忽略反证、有没有更稳妥的分支。

真正需要训练的是推理连接。

## 13. 同时学习两类错误

- 误报：把普通行为误判成隐藏意图；
- 漏报：已经有明显信号却持续忽略。

训练目标是校准，而不是一味“更敏感”。

## 14. 共用核心循环

```text
观察
→ 分离事实与解释
→ 生成候选假设
→ 检查语境
→ 寻找支持证据与反证
→ 评估风险
→ 选择回应
→ 观察结果
→ 更新
→ 回放 / 迁移
```

这条链是本仓库所有书籍、案例和模拟训练的共同基础。
