# 学习来源

## 1. 来源类型

本仓库可以使用三类训练来源：

```text
真实去标识化案例
模拟案例
书籍 / 教材 / 文章中的公开案例
```

三类来源都服务于同一个目标：

```text
输入逐步揭示
→ 当下判断
→ 回应或预测
→ 新信息
→ 修正
→ 迁移
```

## 2. 真实案例

真实案例训练价值高，但隐私风险也最高。

进入仓库前必须经过：必要性检查、去标识化、最小上下文、可公开性检查。

优先保存结构，不保存完整原始聊天记录：

```text
已观察事件
解释所需的最小上下文
我的解释
候选假设
回应
后续结果
判断更新
```

## 3. 模拟案例

模拟案例适合先跑通机制，因为没有第三方隐私问题，可以严格控制信息揭示顺序，也方便针对某个推理缺口重复训练。

首个案例试点优先使用模拟案例。

## 4. 书籍来源

书籍不是为了“读完”才进入仓库，而是为了产生训练输入。

典型流程：

```text
候选书籍
→ 阅读候选清单
→ 选中
→ 主书籍议题
→ 按章节 / 案例原文优先阅读
→ 遇到可训练案例时暂停
→ 学习者先判断
→ 冻结判断或回应
→ 再揭示作者后续分析
→ 比较
→ 更新
→ 迁移
```

## 5. 阅读候选清单与主书籍议题分开

长期阅读候选清单只保存：书名、作者、主题、为什么进入候选、主要训练能力、优先级和状态。

状态只使用：候选、已选中、阅读中、已复盘。

正式开始一本书后，再建立独立主书籍议题。

## 6. 主书籍议题真正追踪什么

不只是“读到第几页”，而是：

```text
当前原文位置
当前概念 / 案例
遇到的推理模式
预测 / 回应练习
误判与理解缺口
迁移问题
下一步行动
```

## 7. 书籍案例训练模式

如果书里出现一个场景，不要立刻看作者解释。

优先：

```text
当前已知原文
↓
字面发生了什么
↓
可能的隐含含义有哪些
↓
哪些证据支持 / 反对
↓
如果是我，下一步怎么回应
↓
冻结预测 / 回应
↓
再揭示作者后续内容
↓
比较
↓
更新
```

这样书籍就从“知识输入”变成“反应机制训练器”。

## 8. 不把作者观点自动升级为事实

沟通类书籍中的作者模型、作者建议、案例解释，仍然要区分：来源主张、推理模型、实证证据、个人适用性。

即使一本书很经典，也不能把作者对人类行为的概括直接写成普遍定律。

## 9. 候选模式的来源

候选模式可以来自多个真实案例、多个模拟案例、多本独立来源，或真实案例与书籍模型交叉验证。

正式晋升仍需要跨案例、反例和语境检查。

## 10. 第一阶段

```text
机制文档
→ 1 个阅读候选清单
→ 选 1 本书
→ 1 个主书籍议题
→ 1 个小案例试点
```

如果这一条链自然，再扩展更多书籍与真实案例。
