# Reasoning Principles

## 1. 目标不是“猜中”，而是建立可修正的判断结构

人际推理的核心不是一次就看穿别人，而是：

```text
输入
→ 建模
→ 保持不确定性
→ 选择回应
→ 等待反馈
→ 更新
```

训练质量主要看：

- 是否区分事实与解释；
- 是否保留替代假设；
- 是否知道还缺什么证据；
- 是否考虑误判成本；
- 是否能在新证据出现后真正改判断。

## 2. Observation First

先问：

```text
我真正观察到了什么？
```

再问：

```text
我把它解释成了什么？
```

禁止把评价词伪装成事实。

例如：

```text
“他态度很差”
```

通常不是原始 observation。

更好的记录是：

```text
回复从完整句变成单字；
连续三次没有回应问题中的第二部分；
语气中没有过去常见的寒暄。
```

## 3. Multiple Hypotheses

任何言外之意分析默认至少问：

```text
还有什么别的解释？
```

可以形成：

```text
H1
H2
H3
...
```

但不要为了数量机械制造极端可能性。

## 4. Evidence For / Against

对每个重要假设，同时问：

```text
什么支持它？
什么反对它？
什么证据如果出现，会让我改变判断？
```

只搜支持自己第一反应的材料属于 confirmation bias，需要显式防止。

## 5. Context Matters

同一句话在不同条件下可能意义完全不同：

```text
关系
权力差异
文化
过往互动
场合
时间压力
公开 / 私下
文字 / 语音 / 面对面
```

因此：

```text
sentence alone ≠ intent
```

## 6. Literal Meaning Before Implicature

分析言外之意时先固定字面层：

```text
literal content
↓
context
↓
possible implicature
```

不要跳过字面层直接“解码”。

## 7. Confidence Must Track Evidence

证据弱时必须允许：

```text
不知道
证据不足
多个解释都合理
```

不确定不是失败，而是正确状态的一部分。

## 8. Response Is a Decision Under Uncertainty

回应不需要等到意图百分百确定。

应比较：

```text
如果 H1 为真，这个回应的效果？
如果 H1 为假，这个回应的代价？
```

在信息不足时优先：

- 可逆；
- 尊重；
- 清晰；
- 不升级冲突；
- 能继续获得信息；
- 能保护必要边界。

## 9. Separate Understanding From Agreement

理解对方可能的需求或立场，不等于同意。

```text
理解
≠
认可
≠
服从
```

人际训练必须保留学习者自己的边界和目标。

## 10. Do Not Overfit Individuals

不要从少量 Case 得出：

```text
“某类人都这样”
“这个人永远会这样”
```

模式必须包含适用条件与失效条件。

## 11. Preserve Prediction Before Reveal

如果做 Prediction：

```text
prediction at T1
↓
freeze
↓
reveal T2
↓
compare
↓
update
```

不能看到结果后修改原 prediction。

## 12. Review the Arrow

复盘重点不是：

```text
我最后猜对了吗？
```

而是：

```text
我为什么从 A 走到 B？
这一步用了什么 cue？
有没有忽略反证？
还有没有更稳妥的分支？
```

真正需要训练的是 reasoning link。

## 13. Learn From False Positives and False Negatives

两类错误都要保留：

```text
False Positive:
把普通行为误判成隐藏意图

False Negative:
已经有明显信号但持续忽略
```

训练目标是校准，而不是一味“更敏感”。

## 14. Reusable Core Loop

```text
Observe
→ Separate Fact / Interpretation
→ Generate Hypotheses
→ Check Context
→ Seek Supporting + Counter Evidence
→ Assess Risk
→ Choose Response
→ Observe Outcome
→ Update
→ Replay / Transfer
```

这条链是本仓库所有书籍、案例和模拟训练的共同基础。
