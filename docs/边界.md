# 仓库边界

## 1. 本仓库负责什么

本仓库负责训练人际场景中的显式输入处理、假设管理、回应选择、反馈更新和复盘迁移。

核心问题是：

```text
在信息不完整、意图不可直接观察的人际互动中，
如何减少脑补和误判，并随着新信息持续修正自己的判断？
```

主要训练场景包括：日常沟通、职场协作、冲突处理、困难对话、谈判、边界表达、言外之意分析、对话复盘、书籍案例和模拟案例训练。

## 2. 本仓库不负责什么

本仓库不是心理诊断系统、人格分类数据库、读心术资料库、操控技巧库、私密聊天记录备份仓库，也不是对第三方真实意图的权威判决系统。

任何关于“对方真实意图”的结论默认只能是候选假设，除非后续出现足够证据。

## 3. 三层必须分离

```text
可观察事实
≠
我的解释
≠
推断出的意图
```

第三层不能反写成第一层。

## 4. 隐私边界

本仓库是公开仓库，真实案例默认去标识化。

禁止提交：真实姓名、手机号、邮箱、住址、社交账号、身份标识、公司内部敏感信息、未经同意的完整私密聊天记录，以及能通过组合信息轻易重新识别个人的细节。

推荐使用：人物甲、人物乙、同事甲、朋友乙、相对时间和必要的最小上下文。

如果一个案例无法在不暴露第三方隐私的情况下公开，就不应进入本仓库。

## 5. 顺序信息边界

训练优先按当时信息顺序展开：

```text
当时已知信息
→ 当时判断
→ 当时回应
→ 新信息揭示
→ 更新
```

禁止先知道最终结果，再伪造“当时就应该看出来”。后见之明只能进入复盘层，不能污染原始判断层。

## 6. 人工智能的角色边界

人工智能可以帮助区分事实与解释、枚举合理候选假设、寻找支持证据和反证、比较不同回应的风险、根据新信息更新判断结构，并帮助复盘推理缺口。

人工智能不应声称知道第三方未表达的真实思想，不应把概率性推断包装成确定事实，不应把刻板印象当证据，也不应以操控他人为训练目标。

## 7. 当前暂不做

机制试点完成前，不做大量迁移过去聊天记录、大规模模式分类、人格标签体系、自动关系评分或自动意图识别。

先证明一个小案例能自然完成：

```text
观察
→ 建立假设
→ 选择回应
→ 揭示新信息
→ 更新
→ 复盘
```
